- [Bugfix] Pin the build-time `setuptools` used inside the isolated PEP 517 build environments that pip creates when building Python packages from source. Previously the latest `setuptools` was fetched to build every sdist regardless of the version installed in the venv, which broke builds when `setuptools` 81 removed `pkg_resources` (e.g. when building `loremipsum`, a transitive dependency of `edx-ora2`). pip 26 always builds sdists in an isolated environment, so this is needed by the pip upgrade above. The constraint is set via `PIP_CONSTRAINT`/`PIP_BUILD_CONSTRAINT` in the base image stage, so it applies to all requirement installs (base.txt, assets.txt, development.txt, extra requirements and editable installs). Backport of #1411. (by @ahmed-arb)
