- [Feature] Add the `OPENEDX_INIT_REINDEX_COURSES` setting (default: `true`). Set it to `false` to skip the synchronous `reindex_course --active` step of CMS init, which can make every launch very slow on instances with many courses. (by @ahmed-arb)
- [Feature] Add the `OPENEDX_REINDEX_COURSES_SCHEDULE` setting (default: `""`). When set to a cron expression, `tutor k8s start` creates a `cms-reindex-courses` CronJob that reindexes active courses on that schedule. Also add the `k8s-cronjobs` patch. `tutor k8s stop` now also deletes CronJobs created by Tutor and its plugins; `tutor k8s start` recreates them. Jobs spawned by CronJobs no longer block `tutor k8s do` commands. (by @ahmed-arb)
