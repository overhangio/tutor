- 💥[Improvement] Remove `dockerize` from the `openedx` image, so that building it no longer pulls an unverified image from Docker Hub (#1303). The init jobs now wait for MySQL and MongoDB with a built-in `wait-for-tcp` script. Plugins that run `dockerize -wait tcp://HOST:PORT` in the `openedx` image should switch to `wait-for-tcp HOST:PORT [TIMEOUT]`. (by @ahmed-arb)
