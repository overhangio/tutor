- [Bugfix] Add an init container to the MongoDB, MySQL, Redis and Meilisearch Kubernetes deployments (unconditionally, on every cluster) that fixes volume ownership before the main container starts. This fixes a crash on first `tutor k8s launch` on clusters whose storage provisioner does not support `fsGroup`, such as Minikube or kind; it is a no-op on clusters where `fsGroup` already works. Air-gapped clusters must now also mirror the `openedx-permissions` image for Kubernetes deployments, not only for `tutor local`. (by @Syed-Ali-Abbas-568)
