- [Security] Upgrade certifi to 2026.10.19, pip to 26.2.2, uv to 0.13.5 and Node.js to v24.22.1 in the Open edX Docker image, and Caddy to 2.11.7, so that they no longer trust the compromised eMudhra/emSign CA certificates (https://emudhra.we-have-a-problem.com/). Also set `PIP_BUILD_CONSTRAINT`, so that the build-time `setuptools` pin keeps applying to source builds made by pip 26, such as editable installs of mounted directories. Rebuild your images with `tutor images build openedx --no-cache` to also get the latest system certificates. If you installed Tutor with pip, upgrade pip and certifi in its environment with `pip install --upgrade pip certifi`. (by @ahmed-arb)
