- [Improvement] Preserve the contents of `config.yml`: comments, blank lines, key order and quoting style all survive a `tutor config save`, and entries that hold a Jinja expression, such as `CMS_HOST: "studio.{{ LMS_HOST }}"`, are no longer flattened to one of their results. The file is now edited in place rather than re-generated, so only the entries that actually changed are written, and commands that change nothing leave it untouched. Expressions that render differently every time, such as `"{{ 24|random_string }}"`, are still frozen to a literal, so generated secrets do not rotate on every load, and values passed to `--set` are still written as literals.
