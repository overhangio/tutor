- 💥[Security] The Redis instance run by Tutor now requires a password, which is generated automatically: run `tutor local launch` (or `tutor dev launch`, `tutor k8s launch`) to apply it on existing installations. The Open edX event bus now connects to `REDIS_HOST` with these credentials, instead of `redis:6379` without them. Plugins that connect to Redis must use `REDIS_USERNAME` and `REDIS_PASSWORD`. (by @ahmed-arb)
