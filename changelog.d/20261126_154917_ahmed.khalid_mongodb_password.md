- 💥[Security] The MongoDB instance run by Tutor now requires authentication. An `openedx` user with a generated password is created when MongoDB starts, including on existing installations: run `tutor local launch` (or `tutor dev launch`, `tutor k8s launch`) to apply it. Commands that you run in the MongoDB container, such as `mongodump`, now need credentials. Plugins that connect to MongoDB must use `MONGODB_USERNAME`, `MONGODB_PASSWORD` and `MONGODB_AUTH_SOURCE`. A custom `command` or `args` of the `mongodb` service is now passed as extra `mongod` options. To disable authentication, for instance with MongoDB images older than 6.0, set `MONGODB_PASSWORD` to "". (by @ahmed-arb)
