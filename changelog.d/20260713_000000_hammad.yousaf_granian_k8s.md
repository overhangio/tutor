- 💥[Feature] Replace uWSGI with Granian as the LMS and CMS web server. (by @mlabeeb03 and @HammadYousaf01)
  - The `uwsgi-config` patch is replaced by `granian-config`, which contains Granian command-line options, one per line.
  - The `OPENEDX_LMS_UWSGI_WORKERS` and `OPENEDX_CMS_UWSGI_WORKERS` settings are renamed to `OPENEDX_LMS_GRANIAN_WORKERS` and `OPENEDX_CMS_GRANIAN_WORKERS`. Existing values are migrated automatically.
  - The `reload-uwsgi` script is replaced by `reload-granian`.
  - Each worker now serves up to 8 requests concurrently, instead of 1 with uWSGI.
  - Static and media files are now served with a `Cache-Control: max-age=86400` header. Add `--static-path-expires` to the `granian-config` patch to change this (0 disables it).
  - On Kubernetes, the `openedx-uwsgi-config` configmap is replaced by `openedx-granian-config`. Run `tutor k8s start --prune-configmaps` to delete the obsolete one.
