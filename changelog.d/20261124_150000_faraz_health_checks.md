- [Improvement] Add a Kubernetes readiness probe to the lms and cms Deployments: pods now only receive traffic once their `/heartbeat` endpoint responds, which reduces 502 errors while new pods are booting. Add startup, readiness and liveness probes to the mysql, mongodb, redis and meilisearch Deployments. Database probes are plain TCP checks, and their startup probes allow 30 minutes, so that long crash recoveries are not interrupted. Probes can be tuned with the `k8s-override` patch. (by @Faraz32123)
- [Improvement] Add Docker Compose health checks to the same services, so that `tutor local status` reports whether they are healthy. Health checks are disabled for lms and cms in development mode, to keep the development server logs readable. They can be tuned in a `docker-compose.override.yml` file. (by @Faraz32123)
