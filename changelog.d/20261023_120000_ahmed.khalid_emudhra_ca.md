- [Security] Upgrade certifi to 2026.10.19, pip to 26.2.2 and Node.js to v22.23.4 in the Open edX Docker image, and Caddy to 2.11.7, so that they no longer trust the compromised eMudhra/emSign CA certificates (https://emudhra.we-have-a-problem.com/). Node.js 20 will not get a fix, so the image moves to Node.js 22. Pull the new image with `tutor images pull openedx`, or rebuild it with `tutor images build openedx` (and `openedx-dev` for `tutor dev`) if you build your own. If you installed Tutor with pip, upgrade pip and certifi in its environment with `pip install --upgrade pip certifi`. (by @ahmed-arb)
