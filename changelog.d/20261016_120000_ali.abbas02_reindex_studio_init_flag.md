- [Bugfix] Pass `--init` back to `./manage.py cms reindex_studio` in the CMS init job. Without it, edx-platform versions that don't yet default `reindex_studio` to the async/incremental behavior (e.g. Ulmo) fall back to a full synchronous reindex on every `init`/`launch`, which can take from several minutes to hours on large instances. `--init` is safe on versions that already default to async/incremental: it only logs a deprecation warning and the task is still enqueued. (by @Syed-Ali-Abbas-568)
